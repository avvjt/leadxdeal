4. LOCAL DEVELOPMENT

---

Prerequisites:

- Node.js
- pnpm

To run the project locally:

1. Clone the repository:
   git clone https://github.com/leadxdeal/leadxdeal.git

2. Navigate to the project directory:
   cd leadxdeal

3. Install dependencies:
   pnpm install

4. Start the development server:
   pnpm dev

5. Open the local website:
   http://localhost:3000

6. IMPORTANT NOTES

---

- Use pnpm to install dependencies and run project scripts.
- Check package.json for the available scripts.
- Configure any required environment variables before running or deploying the project.
- Keep account credentials, API keys, and other secrets private.
- DNS settings for the custom domain must be configured correctly for Vercel.
